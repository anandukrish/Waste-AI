What Venom does

Venom reads the files you explicitly select in the browser. It calculates a SHA-256 hash locally, checks only the first 1 MiB for the EICAR antivirus test string, and applies explainable filename, size, and header heuristics.

High, medium, and low labels indicate how much attention a result deserves. “No local indicator” never means clean, safe, or virus-free.

Nothing is uploaded during local inspection. AI Review is a separate, opt-in action and sends result metadata only to the configured /api/ai-review route.

Not real-time

No background watcher or continuous device protection is active.

Not an engine

No malware definitions, cloud reputation, execution, quarantine, or deletion.

Bounded by design

32 files per batch and 128 MiB per file keep browser work explicit.
